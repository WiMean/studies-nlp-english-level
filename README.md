# Определение уровня английского языка по тексту (мастерская NLP)

**Задача.** Определить уровень владения английским языком (A2, B1, B2, C1) по тексту.

**Что сделано.** Объединение размеченной и неразмеченной выборок, проверка баланса классов, предобработка текста, обучение и сравнение моделей, подбор гиперпараметров.

**Стек.** Python, pandas, scikit-learn, CatBoost, nltk, spaCy
